# NIE Catering – Meal Booking Website

**Location:** VX25+XJ Ruiru · **Price:** KES 50 per plate

## Features

### Login
- **Student** — Full name + phone (no password)
- **Admin** — Name + phone + password (first sign-in sets the password)

### Student
- View today's menu
- Select dishes or Select all
- Book / update plate (KES 50)
- See booking history and collection status

### Admin (Kitchen)
- Publish or replace the day's menu + kitchen note
- Close / reopen booking
- Live stats: bookings, expected revenue, collected
- Mark plates collected as students arrive
- WhatsApp one-tap messages to all booked students
- Admins list

## How to use

1. Unzip and open `index.html` in a browser  
   (or host the folder on any static web server / Netlify / GitHub Pages)
2. All data is stored in the browser's **localStorage** — no backend required for demo use.

Phones accepted as: `0712 345 678`, `712345678`, or `+254 712 345 678`.
